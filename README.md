# 🤖 客盈 AI Agent (Keying AI)

**为餐饮与本地生活门店，打造从公域流量到企微私域、再到店复购的整体增长解决方案。**

## 💡 我们解决的痛点 (The Problem)

*   **内容没少做，到店和复购却没起来**：追热点做内容，与门店定位两张皮；私信高峰没人接，意向客户大量流失。
*   **复购全压在个人身上**：客户加到企微后，跟进全靠员工个人经验，人一离职，私域效果直接归零。
*   **招人贵、风险大**：中小门店养不起全职市场运营，门店真正想要的是一套不用高薪招人、也能拿到经营结果的办法。

## 🚀 我们的解决方案 (The Solution)

我们交付整套落地动作，不卖报告，交付指向到店与复购的执行动作。

*   **01 策略层**：完成门店现状评估，输出内容、人群、营销活动的整套策略。不单独售卖咨询报告。
*   **02 内容层**：按既定策略输出适配抖音、小红书、视频号的物料和发布排期，人工再确认上架，规避风险。
*   **03 转化层**：标准化私信接待流程，合规将意向客户引导到企业微信。
*   **04 私域运营层**：提供客户跟进、营销触达、复购裂变的标准化流程和话术，补齐最后一段闭环。

## 📈 商业进展 (Traction)

*   **种子客户**：3家种子店（日料连锁、精品红酒坊）深度试用，满意度高，明确愿付。
*   **实测效果**：门店内容到私域整条链路的经营效率，实测提升 **10-15%**。
*   **客户反馈**：方案效果强过门店自招初级市场人员，成本更低、见效更快。

## 💰 商业模式 (Business Model)

采用**订阅制**，对标替代门店初级市场岗位的人力成本。

*   **Starter 轻量版** (999元/月)：单店策略驱动内容产出、基础咨询转化话术。
*   **Growth 增长版** (2999元/月)：完整策略-内容-私域闭环，企微线索承接与复购运营。
*   **定制版** (价格面议)：连锁品牌、多品牌集团数据看板与专属服务。
